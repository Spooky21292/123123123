# Playerok Sales Assistant & Chat Bot (Локальный Запуск)

Этот проект представляет собой полнофункциональный кабинет продавца и чат-бот ассистента для торговой площадки **Playerok**.

---

## 🚀 Почему на серверах AI Studio возникает ошибка `403 Forbidden`?

Оригинальный сайт `playerok.com` использует мощную защиту **Cloudflare**. Cloudflare автоматически анализирует IP-адреса, с которых поступают запросы. 
- Облачные сервера (такие как Google Cloud, AWS, Vercel, Cloud Run), на которых крутится превью в AI Studio, имеют **серверные (datacenter) IP-адреса**. Cloudflare мгновенно блокирует их и выдает ошибку `403 Forbidden`.
- **Но когда вы запустите это приложение на своем домашнем ПК**, запросы будут отправляться с вашего обычного **домашнего (residential) IP-адреса**. Cloudflare **не будет блокировать вас**, и все запросы к профилю, сделкам и чатам Playerok будут проходить идеально прямо через ваш собственный прокси-сервер!

## 💻 Инструкция по локальному запуску на вашем ПК

Выполните следующие простые шаги, чтобы запустить приложение локально:

### Шаг 1: Скачайте исходный код проекта
1. В верхнем правом углу интерфейса **Google AI Studio** нажмите кнопку настроек/экспорта (обычно иконка шестеренки или кнопка рядом с кнопкой Share).
2. Выберите опцию **"Download ZIP"** (Скачать ZIP-архив) или свяжите проект с вашим **GitHub** аккаунтом.
3. Распакуйте скачанный ZIP-архив в любую удобную папку на компьютере.

### Шаг 2: Установите Node.js
Убедитесь, что на вашем компьютере установлен современный Node.js (версии 18, 20 или новее).
- Если он у вас не установлен, скачайте и установите его с официального сайта: [https://nodejs.org/](https://nodejs.org/) (рекомендуется LTS версия).

### Шаг 3: Установите зависимости проекта
1. Откройте командную строку (Терминал / PowerShell / Терминал VS Code) в папке с проектом.
2. Введите следующую команду для установки всех библиотек:
   ```bash
   npm install
   ```

### Шаг 4: Запустите локальный сервер разработки
Запустите команду, которая поднимет локальный full-stack сервер (Express + Vite) на вашем компьютере:
   ```bash
   npm run dev
   ```
Вы увидите сообщение в терминале:
   ```
   Server running on http://0.0.0.0:3000
   ```
Теперь откройте в вашем браузере ссылку: **[http://localhost:3000](http://localhost:3000)**.

##🔑 Как получить токен авторизации (Bearer Token) с Playerok

Для того чтобы приложение могло автоматически читать ваши заказы, отправлять сообщения в чаты и выводить статистику, ему необходим авторизационный токен вашего аккаунта.

Вот как легко его получить через браузер:

1. Перейдите на сайт **[playerok.com](https://playerok.com/)** на вашем ПК и войдите в свой аккаунт.
2. Нажмите клавишу **F12** на клавиатуре (или кликните правой кнопкой мыши в любом месте страницы и выберите **«Посмотреть код»** / **«Исследовать элемент»**), чтобы открыть панель разработчика.
3. Перейдите во вкладку **Application** (Приложение) сверху (в некоторых браузерах она называется *Storage* или *Хранилище*).
4. В левом сайдбаре разверните раздел **Cookies** (Куки) и выберите строку `https://playerok.com`.
5. Найдите куку с названием **`token`**. Скопируйте её значение (это длинная строка букв и цифр).
6. **Альтернативный способ:**
   - Перейдите во вкладку **Network** (Сеть) в панели разработчика.
   - Обновите страницу Playerok.
   - Кликните на любой запрос в списке (например, начинающийся с `api` или `me`) и в правой части в подразделе **Request Headers** (Заголовки запроса) скопируйте всю строку после `Authorization: Bearer ...`.
7. Скопированный токен вставьте в поле **«Токен авторизации»** во вкладке **«Настройки»** внутри нашего запущенного локально приложения и нажмите **«Сохранить токен»**.

Сразу после этого индикатор подключения на главном экране локального приложения загорится зеленым цветом, подтверждая успешное соединение, и вы увидите ваши реальные сделки, переписки и баланс!

## 🛠️ Команды в проекте

- `npm install` — первоначальная установка зависимостей.
- `npm run dev` — запуск в режиме разработки (быстрый запуск с автоматическим обновлением кода).
- `npm run build` — сборка проекта в оптимизированные файлы для продакшна.
- `npm run start` — запуск скомпилированной версии на максимальной скорости.
